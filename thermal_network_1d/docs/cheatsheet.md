# 1D 熱回路網 チートシート

## 電気-熱アナロジー

| 電気 | 熱 | 備考 |
|---|---|---|
| 電圧 V [V] | 温度 T [K] | 差だけが意味を持つ |
| 電流 I [A] | 熱流 Q [W] | 保存量 |
| 抵抗 R [Ω] | 熱抵抗 R [K/W] | 「1 W 流すと何 K 上がるか」 |
| 静電容量 C [F] | 熱容量 C [J/K] | C = ρ cp V |
| 電流源 | 発熱 Q [W] | ジュール発熱・損失 |
| 電圧源 | 温度固定境界 | 大気・冷却水など |
| I = V/R | Q = ΔT/R | オームの法則 |

熱には「インダクタンス」に相当するものが(通常の伝熱では)ない。
したがって熱回路は必ず 1 次系の集まりであり、振動しない(単調応答)。

## 熱抵抗の公式

| 経路 | 式 | 単位・注意 |
|---|---|---|
| 平板伝導 | `R = L / (k A)` | 最も基本 |
| 円筒伝導 | `R = ln(r2/r1) / (2π k L)` | 配管・電線 |
| 球殻伝導 | `R = (1/r1 - 1/r2) / (4π k)` | タンク |
| 対流 | `R = 1 / (h A)` | h は相関式から |
| 輻射 | `R = 1 / (h_r A)`, `h_r = ε F σ (Ts+Tsur)(Ts²+Tsur²)` | 絶対温度で計算 |
| 接触 | `R = 1 / (h_c A)` または `R = 熱抵抗率 / A` | TIM のカタログ値は [m²K/W] |
| フィン | `R = 1 / [h (A_base + N η A_fin)]`, `η = tanh(mLc)/(mLc)` | `m = √(2h/(k t))` |
| 拡がり | 半無限体 等温 `1/(4ka)` / 等熱流束 `8/(3π²ka)` | 小熱源で支配的 |
| 流体の昇温 | `R = 1/(ṁ cp)`(出口基準)、`1/(2 ṁ cp)`(平均基準) | 強制空冷で必須 |

## 判定に使う無次元数

- **ビオ数** `Bi = h Lc / k` … < 0.1 なら 1 ノード(集中定数)でよい
- **フーリエ数** `Fo = α t / Lc²` … 過渡の進み具合。`Fo > 0.2` で指数減衰域
- **レイリー数** `Ra = g β ΔT L³ / (ν α)` … 自然対流の強さ、層流/乱流の判定
- **レイノルズ数** `Re = u L / ν` … 強制対流。平板 5×10⁵、円管 2300 が遷移の目安
- **ヌセルト数** `Nu = h L / k_fluid` … 相関式はこの形で与えられる

## よく使う対流相関式(空気)

| 状況 | 相関式 |
|---|---|
| 垂直平板 自然対流 | Churchill–Chu: `Nu = {0.825 + 0.387Ra^(1/6)/[1+(0.492/Pr)^(9/16)]^(8/27)}²` |
| 上向き高温水平面 | `Nu = 0.54 Ra^(1/4)` (10⁴–10⁷), `0.15 Ra^(1/3)` (10⁷–10¹¹), Lc = A/P |
| 平板 強制対流 | 層流 `Nu = 0.664 Re^(1/2) Pr^(1/3)`、混合 `Nu = (0.037Re^(4/5) - 871)Pr^(1/3)` |
| ダクト内 | 層流十分発達 `Nu = 4.36`(等熱流束)/ `3.66`(等温)、乱流 `Nu = 0.023Re^(4/5)Pr^0.4` |

物性は**膜温度** `(Ts + T∞)/2` で評価する。

## 節点方程式

```
C_i dT_i/dt = Q_i + Σ_j (T_j - T_i)/R_ij
```

行列形: `C dT/dt + A T = b`

- `A[i,i] = Σ_j G_ij`, `A[i,j] = -G_ij`, `G_ij = 1/R_ij`
- 境界(温度固定)はその行を `T_k = T_fixed` に置換
- θ 法: `(C/Δt + θA) T^{n+1} = (C/Δt - (1-θ)A) T^n + θb^{n+1} + (1-θ)b^n`
  - θ=1 後退オイラー(無条件安定・1 次精度)
  - θ=0.5 クランク・ニコルソン(2 次精度)
  - θ=0 前進オイラー(`Δt < 2/λ_max` でないと発散)

## CFD を 1D 化する手順

1. **経路を切る** … 物理的に意味のある境界(部品/界面/流体)でノードを置く
2. **代表温度を決める** … CFD 結果から**面積加重平均**で拾う(最高温度と混ぜない)
3. **抵抗を作る** … `R = (T_i - T_j) / Q_ij`。分母はその区間を実際に通る熱流
4. **回路を再構成** … 組み直して CFD と一致するか確認(一致しなければ経路の切り方が誤り)
5. **適用範囲を明記** … 形状・流量・h・発熱分布のどこまで流用できるかを書く

## 1D 化でやりがちなミス

| ミス | 症状 | 対策 |
|---|---|---|
| 拡がり抵抗の抜け | 小熱源で温度を 10–30 % 過小評価 | `R_spread` を CFD か相関式から足す |
| 流体の昇温を無視 | 風量が少ないほど大きく外す | `R = 1/(2ṁcp)` を直列に入れる |
| 最高温度と平均温度の混同 | 抵抗が系統的にずれる | 定義を決めて一貫させる(面積加重平均推奨) |
| 輻射の無視 | 自然空冷で 3–5 割の誤差 | `h_r` を並列枝に |
| h の決め打ち | 10 K 単位でずれる | 相関式か CFD 校正を使う |
| ファン特性の無視 | 「フィンは多いほど良い」という誤結論 | 圧損とファン曲線の交点を解く |
| Bi > 0.1 で 1 ノード | 内部温度差ぶん過小評価 | ノードを分割する |
| 過渡が定常に未到達 | R も C も同定を誤る | 最遅時定数の 5 倍まで回す |

## モデルファイルで回すとき

抵抗を手計算せず YAML に物理量を書く方法は `docs/model_format.md`。要点だけ:

```bash
python -m thermalnet.model models/cpu_heatsink.yaml
python -m thermalnet.model models/cpu_heatsink.yaml --set nodes.die.heat=125
python -m thermalnet.model models/cpu_heatsink.yaml --sweep nodes.die.heat=50:150:11 --watch die
python -m thermalnet.model models/power_module_liquid.yaml --transient --plot out.png
```

- **直列にしたいなら中間ノードを挟む**。同じ 2 ノード間に 2 本書くと並列合成される
- `type: flow` の `mean: true` は `1/(2ṁcp)`(平均温度基準)、`false` は `1/(ṁcp)`(出口基準)
- `type: spreading` の `h` は `h: auto` にすると下流の合成抵抗から自動整合される
- `correlation:` を使うと h が温度の関数になり自動で非線形反復になる
- `disabled: true` でその要素だけ外して効果を切り分けられる

## レポートに必ず書くこと

1D モデルは数字がいくらでも出るので、結果だけのレポートは事故のもと。
`python -m thermalnet.report` はこの型で自動生成する:

1. **判定** — 何度になったか、上限に対して何 K の余裕か
2. **主熱流経路** — どこを通って熱が逃げているか(分岐と区別する)
3. **熱抵抗の内訳** — 支配抵抗はどれか。対策の優先順位はここで決まる
4. **感度** — 何を何 % 改善すると何 K 下がるか(暗算ではなく解き直した値)
5. **検算** — エネルギー保存の残差、反復の収束、主経路の網羅率
6. **前提と適用限界** — 相関式の適用範囲、拡がり抵抗の仮定、流量の扱い、
   界面熱抵抗のばらつき。**ここを書かないモデルは使い回されて事故になる**
