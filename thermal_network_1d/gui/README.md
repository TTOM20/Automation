# ブラウザ GUI

サーバも外部ライブラリも不要です。ファイルをブラウザで開けば動きます。
版が 2 つあります。**まずは軽い方(熱回路ベンチ)から**どうぞ。

| ファイル | 中身 |
|---|---|
| `thermal_bench.html` | **熱回路ベンチ** — 要素は 4 つだけの最小構成 |
| `thermal_circuit_studio.html` | **熱回路スタジオ** — 相関式・過渡解析つきの全部入り |

---

## 熱回路ベンチ (`thermal_bench.html`)

扱う要素はこの 4 つだけです。

| 要素 | 意味 | 回路のたとえ |
|---|---|---|
| **ノード** | 温度が決まる点 | 節点 |
| **枝** | ノード間の熱抵抗 `R [K/W]` | 抵抗 |
| **発熱** | ノードに入る熱 `Q [W]` | 電流源 |
| **温度固定** | ノードの温度を決める境界 `[degC]` | 電圧源 |

解いているのは節点法の式そのものです。

```
Σ_j (Ti - Tj)/Rij = Qi        (自由ノード)
Ti = Tfixed                   (温度固定ノード)
```

### 操作

| やりたいこと | 操作 |
|---|---|
| ノードを足す | `＋ ノード` ボタン / `N` / 空白をダブルクリック |
| つなぐ | ノード右上の **＋** を相手のノードへドラッグ(または選んで「つなぐ」→ 相手をクリック) |
| 値を変える | 選んで右パネルで編集(**打った瞬間に再計算**) |
| 消す | 選んで `Delete` またはツールバーの「削除」 |
| 動かす | ノードをドラッグ / 背景をドラッグでパン / ホイールで拡大縮小 |
| 並べ直す | 「整列」(温度固定ノードからの段数で列を作る。発熱側が左) |

数値を打っている間、入力欄も表の行も**一切動きません**。
インスペクタは選択が変わったときだけ組み直し、入力中は SVG の属性と数字だけを書き換えます。
表の行は温度順ではなく**追加順で固定**しています(値で並べ替えると入力中に行が飛ぶため)。

### 見方

- ノードの色 = 温度(左下のカラーバー)
- 枝の**太さ** = 熱流の大きさ、**流れる破線と矢印** = 熱の向き
- 右パネルに温度一覧・枝ごとの熱流・**検算**(発熱の合計 / 固定ノードへの流出 / 収支の残差)
- 温度固定ノードが無い、境界につながらない浮きノードがある、R が 0 以下 — は解く前に警告します

### R をその場で計算する

枝を選ぶと「R を寸法から計算する」が開けます。値を入れて `R へ` を押すと上の R に入ります。

| | 式 |
|---|---|
| 伝導 | `R = L / (k A)` |
| 対流 | `R = 1 / (h A)` |
| 流体の持ち去り | `R = 1 / (mdot cp)` |

### Python 版との行き来

- `YAML` ボタン → `type: resistance` の素直なモデルファイルが出ます。
  そのまま `python -m thermalnet.model model.yaml` や `python -m thermalnet.report model.yaml` に渡せます。
- `JSON` ボタンで保存・読み込み。編集中の回路はブラウザの localStorage にも自動保存されます。

## 熱回路スタジオ (`thermal_circuit_studio.html`)

物性や寸法から抵抗を作りたい場合、時間変化を見たい場合はこちら。

- **ノード**: 発熱 [W]、温度固定 [degC]、熱容量 [J/K]
- **要素**: 伝導 / 界面(TIM) / 対流 / 輻射 / フィン / 拡がり抵抗 / 流体への排熱 / 直接指定
- **対流・輻射** は相関式(自然対流・強制対流・ダクト内)を選ぶと熱伝達率が温度の関数になり、
  非線形反復で解きます
- **過渡モード** では熱容量を含めて時間積分し、再生ボタンで温度が動く様子を見られます
- 例題: 空冷 CPU / 多層壁と熱橋 / ファンレス筐体 / パワーモジュール水冷

計算式は Python 版 `thermalnet/elements.py` `fluids.py` `network.py` と同一です
(節点法、theta 法の後退オイラー、非線形は緩和付き不動点反復)。

---

## つまずきやすいところ

**同じ 2 ノード間に 2 本引くと直列ではなく並列になります。**
拡がり抵抗と TIM のように「順番に通る」ものは、間に中継ノードを 1 つ置いてください。
ベンチの「並列 2 経路」の例題は、これをわざと並列にして分流を見るためのものです。
