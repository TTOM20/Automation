# 熱回路スタジオ (GUI)

`thermal_circuit_studio.html` はブラウザだけで動く 1D 熱回路シミュレータです。
サーバも外部ライブラリも不要 — ファイルをブラウザで開けば動きます。

```bash
# ローカルで開く
xdg-open gui/thermal_circuit_studio.html      # macOS なら open
```

## できること

| 操作 | やり方 |
|---|---|
| ノードを足す | `N` を押して空白をクリック |
| ノードを動かす | ドラッグ |
| 要素でつなぐ | 左のパレットで種類を選ぶ → ノード A → B をクリック(`C` でも切替) |
| 値を変える | ノード / 要素を選んで右パネルで編集(その場で再計算) |
| 消す | 選んで `Delete` |
| 画面移動 | 背景をドラッグ / ホイールで拡大縮小 / 「整列」で自動配置 |

- **ノード**: 発熱 [W]、温度固定 [degC](境界)、熱容量 [J/K]
- **要素**: 伝導 / 界面(TIM) / 対流 / 輻射 / フィン / 拡がり抵抗 / 流体への排熱 / 直接指定
- **対流** は相関式(自然対流・強制対流・ダクト内)を選ぶと熱伝達率が温度の関数になり、
  非線形反復で解きます。輻射も同様。
- **過渡モード** では熱容量を含めて時間積分し、再生ボタンで温度が動く様子を見られます。

## 見方

- ノードの色 = 温度(左下のカラーバー)。枝の**太さ** = 熱流の大きさ、**流れる破線** = 熱の向き。
- 右パネルに熱抵抗の内訳(主熱流経路上の要素は青いマーク付き)、ノード温度、検算
  (エネルギー収支の残差・反復回数)が出ます。
- 温度指定ノードが無い / 境界につながっていないノードがある場合は、解く前に警告します。

## Python 版との行き来

- 右下「YAML で書き出す」→ そのまま `python -m thermalnet.model model.yaml` で解けます。
  レポート生成 `python -m thermalnet.report model.yaml` にもかけられます。
- JSON で保存・読み込みもできます(ブラウザの localStorage に自動保存されます)。

計算式は Python 版 `thermalnet/elements.py` `fluids.py` `network.py` と同一です
(節点法、theta 法の後退オイラー、非線形は緩和付き不動点反復)。
